Machine Tokens

New Machine Token

Machine tokens are bearer credentials for clients that can't present a GitHub Actions OIDC token (e.g. webhook-runner hooks). Each token is bound to one environment; presenting it to GET /github/v1/secrets vends that environment's secrets. Only the token's hash is stored — the value is shown once, at creation.
